This walks you through running a basic MIPS program on the processor in Logisim.
Using the tools installed in the prior subsections, this provides guide for the workflow necessary to run MIPS programs
in Logisim-Evolution with LogiSpim.
Each subsection is briefly explained below:

### [Written Guide](2_2_1_written_guide.md) *(Recommended)*
This guide has step-by-step instructions with visual aids to walk you through the process of creating, compiling,
importing, and running your MIPS program by using an example "Hello, world!" program.

### [Video Guide](2_2_2_video_guide.md)
This brief video guide walks you through using LogiSpim to execute a basic "Hello, world!" MIPS program.
