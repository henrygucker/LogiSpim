This section covers how to install and set up LogiSpim.
It is broken up into steps that must be taken prior to installation of LogiSpim, and steps for the installation of
LogiSpim that are to be done once all prerequisite steps have been completed.
Each subsection is briefly explained below:

### [Prerequisite Installation](2_1_prerequisite_installation.md)
This subsection explains how to install the third-party tooling required for the project to be used.
With separate tutorials for different operating systems, this covers critical steps to ensure LogiSpim can be
used as intended.

### [Installation](2_2_installation.md)
This subsection describes how to download and set up LogiSpim for use.
It covers Logisim-Evolution, the `.circ` file, and setting up the File Processor program.
